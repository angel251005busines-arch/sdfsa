# Как запустить — коротко

Нужен **только Python 3.10 или новее**. Ничего больше устанавливать не надо.

## Шаг 1. Скопировать проект на компьютер или сервер

```bash
git clone https://github.com/angel251005busines-arch/sdfsa.git
cd sdfsa
```

Нет `git`? Скачайте архив: <https://github.com/angel251005busines-arch/sdfsa/archive/refs/heads/main.zip>,
распакуйте и зайдите в получившуюся папку.

## Шаг 2. Запустить

**Linux / macOS:**

```bash
./start.sh
```

**Windows:** двойной клик по `start.bat` (или в командной строке: `start.bat`).

Если `start.bat` выдаёт странные ошибки вида `'а' is not recognized as an internal
or external command` — запустите ту же команду вручную (это всегда работает):

```bat
cd C:\путь\к\sdfsa
py -3 -m boolgen.cli serve
```

Если `py` не найден, используйте `python -m boolgen.cli serve` или `python3 -m boolgen.cli serve`.

Если скрипт не запускается — та же команда вручную:

```bash
python3 -m boolgen.cli serve
```

## Шаг 3. Открыть в браузере

<http://127.0.0.1:8000>

Браузер обычно открывается сам. На странице: выберите тип задания, операции,
сложность, количество → «Сгенерировать».

Остановить сервер: `Ctrl+C` в том же окне терминала.

## Вход и персональная статистика

Запустите сервер с флагом `--auth`, чтобы разные пользователи могли пользоваться
программой на одном ПК:

```bash
./start.sh --auth
```

После этого в браузере (<http://127.0.0.1:8000>):

1. **Регистрация** — придумайте логин (мин. 3 символа) и пароль (мин. 4).
2. **Вход** — вы попадаете на главную страницу генератора.
3. **Задание** — генерируйте и решайте задания. Каждый ответ сохраняется в
   вашу личную базу (`data/users/<логин>/pool.sqlite`).
4. **Статистика** — откройте <http://127.0.0.1:8000/me/stats>, чтобы увидеть
   сколько заданий решено, сколько верно, разбивка по типам и сложности.

Выход — `/logout` в адресной строке.

Основной код `boolgen/` не менялся: аутентификация и статистика реализованы в
новых файлах `boolgen/auth/` (пользователи, сессии, персональные пулы,
обёртка сервера, веб-маршруты).

## Мелочи, которые могут пригодиться

| Что нужно | Как |
|---|---|
| Другой порт | `PORT=9000 ./start.sh` |
| Доступ с других машин (сервер) | `HOST=0.0.0.0 ./start.sh`, затем открывать `http://<ip-сервера>:8000` |
| «Трудная» сложность не генерируется | в форме поставьте глубину 4 или 5 |
| Порт занят | `PORT=8001 ./start.sh` |
| Windows: `'а' is not recognized...` в `start.bat` | старая версия файла с русским текстом; обновите проект (`git pull`) или запустите `py -3 -m boolgen.cli serve` вручную |
| Проверить, что всё работает | `python3 -m boolgen.cli selftest` |
| Посмотреть примеры заданий в консоли | `python3 -m boolgen.cli demo --count 1` |
| Прогнать тесты | `python3 -m unittest discover -s tests -t .` |

Подробное описание архитектуры и всех возможностей — в [README.md](README.md).
